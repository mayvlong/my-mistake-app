# 部署说明

这个文件夹可以直接上传到任意静态托管平台。所有资源都用**相对路径**（`./`），所以部署在根域名或子路径（如 GitHub Pages 的 `/仓库名/`）都能正常打开。

```
mistake-review-assistant-deploy/
├── index.html          单文件应用（CSS/JS 全内联，无外部依赖）
├── manifest.json       PWA 清单：名称、图标、独立窗口
├── sw.js              极简 Service Worker：只缓存外壳，实现离线打开
├── icons/
│   ├── icon-192.png
│   └── icon-512.png
└── docs/
    └── 部署说明.md      本文件
```

部署完访问 `https://你的域名/index.html`（或直接 `https://你的域名/`，多数平台会自动找 index.html）。**必须是 https**，否则 Service Worker 不生效、添加到主屏幕的体验也会降级。

---

## 一、Vercel（最快，30 秒）

1. 打开 <https://vercel.com>，登录。
2. 首页点 **Add New → Project**，选 **Deploy from a template** 下方的 **Upload**（或直接把整个 `mistake-review-assistant-deploy` 文件夹拖进浏览器窗口）。
3. 项目名随便（例如 `mistake-review`），Framework Preset 选 **Other**，Build Command / Output 全部留空。
4. 点 **Deploy**，等 10 秒左右，得到 `https://mistake-review-xxxx.vercel.app`。
5. 手机扫二维码或直接打开这个网址即可。

> 以后改了内容：重新拖一次文件夹，或在 Vercel 项目里 **Deployments → 右侧 … → Redeploy**。

## 二、GitHub Pages（免费、可长期保存）

1. 新建仓库（Public），例如 `mistake-review`。
2. 把 `mistake-review-assistant-deploy` 里面的**所有文件**上传到仓库根目录（网页版 **Add file → Upload files** 直接拖进去即可，注意是文件本身，不要多套一层文件夹）。
3. 仓库 **Settings → Pages**：Source 选 **Deploy from a branch**，Branch 选 `main`、目录选 `/ (root)`，点 **Save**。
4. 等 1 分钟左右，地址是：`https://你的用户名.github.io/mistake-review/`
5. 首次打开可能 404，等 1～2 分钟再刷新。

> 更新：重新上传改动的文件，Pages 会自动重新发布（可能要等 1 分钟）。

## 三、手机上「添加到主屏幕」

**iPhone / iPad（Safari）**
1. 用 **Safari** 打开网址（必须 Safari，微信内置浏览器不行）。
2. 点底部中间的 **分享** 按钮（方框向上箭头）。
3. 下滑点 **添加到主屏幕** → 名字默认「错题本」→ 点 **添加**。
4. 桌面出现图标，点开是全屏独立窗口，没有地址栏。

**Android（Chrome / Edge）**
1. 用 Chrome 打开网址。
2. 右上角 **⋮** → **添加到主屏幕**（部分机型写作「安装应用」）。
3. 确认后桌面出现图标，打开为独立窗口。

> 第一次打开需要联网加载；之后 Service Worker 已缓存外壳，断网也能打开（数据本来就在本机）。

## 四、电脑 Chrome 安装为应用窗口

1. 用 Chrome 打开部署好的网址。
2. 地址栏右侧点 **安装图标**（显示器加箭头）→ **安装**。
   找不到图标时：右上角 **⋮ → 保存并分享 → 安装页面为应用**（旧版为「更多工具 → 创建快捷方式」，勾选「在窗口中打开」）。
3. 安装后从开始菜单/程序坞启动，是独立窗口，任务栏独立显示，和原生应用一样。

## 五、常见问题

| 现象 | 原因 / 处理 |
|---|---|
| 电脑上不显示"安装"图标 | 必须是 https（或 localhost）；图标要能访问到；刷新一次再等几秒 |
| 手机上添加到主屏幕后图标是白底 | 清理 Safari/Chrome 缓存后重新添加；确认 `./icons/icon-192.png` 能直接打开 |
| 改了代码但打开还是旧版 | Service Worker 缓存了外壳。手机端把应用删除后重新添加；电脑端开发者工具 **Application → Service Workers → Unregister** 再刷新 |
| 部署在子路径打不开图标 | 本项目的路径全是 `./` 相对写法，正常不会出问题；确认 `icons/` 目录一起上传了 |
| 换了网址数据不见了 | 正常现象：数据按"域名 + 路径"隔离，`file://`、`http://localhost`、线上 https 是**三套独立存储**。换环境前先在设置里**导出 JSON**，新环境再导入 |
| 图片存不进去 | 进 **设置 → 存储诊断**，点开始诊断，看 `openDB` 与 `protocol` 两行。https 下一般可用；若显示不可用，说明浏览器限制了 IndexedDB（如部分隐私模式） |

## 六、安全说明

- **托管平台只分发静态文件。** 你的错题、配图、复习记录全部只写入**你自己设备的浏览器**（IndexedDB 存图片、LocalStorage 存文字与设置），服务器上不保存任何学习数据，也没有账号体系和服务端接口。
- **不要把任何 API Key 硬编码进 `index.html`。** 「AI 复盘」页第一版只是占位：字段只保存在本机 LocalStorage，**不发任何网络请求**（全仓库无 `fetch` / `XMLHttpRequest`）。后续接 Ollama 或 OpenAI 兼容接口时，Key 也应留在用户本机设置里，不要写进代码。
- **本地数据默认不加密。** 能解锁你手机/电脑的人，用同一浏览器就能看到这些内容；设备丢失时存在被读取的风险。建议定期用 **设置 → 导出 JSON** 做备份，重要内容不要只留一份在本机。
